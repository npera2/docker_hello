# 2026-10-08 工作日志

## docker_hello 项目：修复国内网络下 Docker 构建/拉取失败

### 现象
`docker run -d -p 8000:8000 docker_test` 报错：
`failed to fetch oauth token: Post "https://auth.docker.io/token": dial tcp 162.125.32.10:443 ...`

### 根因（已实测确认）
1. **DNS 污染**：本机 `auth.docker.io` 被解析到 `31.13.94.10`（Meta/Facebook IP）与
   `2a03:2880:...:face:b00c...`；`registry-1.docker.io` 直连超时（curl 返回 000）。
   → Docker 无法访问 Docker Hub 官方认证接口。
2. **本地无 `python:3.13-slim`**：Dockerfile 的 `FROM python:3.13-slim` 需联网拉取，
   而 `docker_test` 镜像也不存在，于是整条链在构建阶段就崩了。
3. **清华 PyPI 源在本线路返回 403 Forbidden**（pip 表现为 "No matching distribution found"）。
   阿里云源 `https://mirrors.aliyun.com/pypi/simple/` 返回 200，可用。

### 环境事实（本项目）
- Docker Desktop 4.94.0 / Engine 29.8.2 / containerd v2.3.6（**已启用 containerd 镜像存储**）
- `C:\Users\包子\.docker\daemon.json` 原**未配置** `registry-mirrors`（已备份为 `daemon.json.bak`）
- 本机可达的国内镜像源（2026-10-08 实测）：
  `docker.1ms.run`(401/OK)、`docker.xuanyuan.me`(OK)、`docker.m.daocloud.io`(OK)、
  `dockerproxy.net`(200)、`hub.rat.dev`(302)

### 已解决方式（无需重启 Docker 的绕行法，最有效）
```bash
docker pull docker.1ms.run/library/python:3.13-slim
docker tag  docker.1ms.run/library/python:3.13-slim python:3.13-slim  # 命中本地，BuildKit 不再联网
docker build -t docker_test .
docker run -d -p 8000:8000 --name docker_test_run docker_test
curl http://localhost:8000/   # -> {"hello":"dbkuaizi"} 验证通过
```

### 代码变更
- `Dockerfile`：`RUN pip install -r requirements.txt` 改为
  `RUN pip install --no-cache-dir -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/`

### 永久修复（已完成）
